# Style & Branding

This directory contains style guides, branding documentation, and visual design standards for the CtxRtr project.

## ■ Contents

- `unified-style-system.md` - the current, canonical style system: ASCII-first monochromatic design, naming standards, and the no-emoji Unicode symbol policy
- `ascii-style-guide.md` - detailed ASCII/box-drawing reference and examples
- `coding-standards.md` - bash scripting conventions (safety boilerplate, error handling, logging, naming)
- `naming-guidelines.md` - project name usage rules (correct vs. incorrect forms)
- `readme-standard.md` - the expected structure for a directory README
- `advanced-blockquote-nesting.md` - markdown blockquote nesting conventions
- `style-system-implementation-summary.md` - historical record of the original DigitalEnv-to-CtxRtr style rollout, kept as-is
